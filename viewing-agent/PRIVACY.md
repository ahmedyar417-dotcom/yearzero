# Viewing Agent: privacy policy

Viewing Agent is a personal tool used by one person, Ahmad Yar, to arrange rental property viewings by email. It is not offered to the public.

**What it accesses:** the owner's own Gmail account, where it reads emails from letting agents and landlords about properties the owner has listed and sends replies, and the owner's own Google Calendar, where it checks busy times and adds booked viewings.

**What it does with the data:** it uses email content only to reply about viewings. To draft replies, it sends the relevant email text to Anthropic's Claude API. It keeps a small record (message IDs and booked times) in the owner's private GitHub repository. It does not sell, share or publish any data.

**Who can use it:** only the owner. No other users' data is accessed.

**Removing access:** the owner can revoke access at any time at <https://myaccount.google.com/permissions>.
